# Stone photos

`kvetko.png` is a transparent cutout prepared from the user-provided Kvetko photograph with the built-in imagegen tool. Its portrait is selected by stone ID `SF70489F2C749F909` in `docs/app.js`; other stones retain their configured images.

Prompt used:

> Use case: background-extraction. Edit target: the attached photograph of the painted oval stone (flowers in blue, yellow and white with red centers). Asset: real photographed Kvetko stone for a small website card on a dark background. Remove only the white background and its cast shadow, making actual transparency around the stone. Preserve the exact stone outline, original camera angle, surface texture, hand-painted flower arrangement, colors and all details. Do not redraw, stylize, invent, or alter the stone. Keep entire stone visible, centered with a small transparent margin (about 5 percent) on a square canvas. No text, no embellishments. Save the resulting transparent PNG to the generated images directory so it can be used in the repository.
